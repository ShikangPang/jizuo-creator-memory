# 人物 skill

已引用或明确指定当前对象时，用户要求生成、创作、优化或修改提示词后，若尚未选视图，先在对话中请用户选择；视图明确后读取最新项目并用 jizuo_replace_design_prompt 直接保存完整基础提示词，再展示包含本次布局和画风的完整结果；不再要求用户复制或点击替换。明确只讨论或先不保存时不写入，目标不明确时不猜测。

本技能是对应对象的创作入口。需要读取或保存项目时，同时加载 creative-prompt 作为共用操作流程；不能用共用流程替代本技能的构图、视图与专业创作要求。

生成或优化提示词时，在聊天回复中展示可直接使用的完整纯文本代码块，包含基础描述、当前布局的完整规则和作品统一画风。不要只说“系统会追加”。保存、讨论和付费生成的边界遵循 creative-prompt；基础设定与布局分开保存，明确的用户布局要求优先于推荐。

未指定布局时推荐 view=character-sheet：同一张横向画布上两行三列，上排正面、侧面、背面全身，下排正面脸部、侧面脸部和辨识特征特写。用户明确选择 turnaround 时保留原三视图；其他 view 仅使用对应规则，不能同时追加六宫格和单视图要求。三视图、六宫格都是一张图片，生成数量为 1。全身“照片”表示取景范围，不要求写实摄影，实际表现继承作品画风。

从设定库进入优化对话时，如果引用没有 requestedView、作者也未在对话中指定视图，先请作者选择：六宫格（推荐）、三视图、正面、侧面、背面、表情或服装。收到选择后再写包含该视图规则的完整图片提示词；推荐项不能当成作者已选。基础人物描述仍可独立讨论，不把视图排版保存进 description。
作者另外明确要求生成图片时，使用已选视图作为 jizuo_generate_video_media 的 view；仅讨论或优化提示词时不提交生成任务。

先读取最新角色设定、所选视图与参考图，保留人物事实和左右特征。保存 description 时仅保存稳定身份与外观；生成任务按 view 自动追加完整布局。不要将六宫格布局带入单镜头视频。跨人物与场景的提取规则见 scene-prompts 的 design-authoring 和 design-description。

## 作品统一画风（人物、场景和剧情共用）

下列三块为三类 skill 的公共规则，场景和剧情创作也读取本节。没有配置画风时不自行指定；style-authoring 指导文字模型，style-generation 加入可见媒体提示词，style-references 仅在真实传入画风参考时用实际顺序替换 {{positions}}。

```prompt:style-authoring
visualStyle 是作品统一的视觉风格数据，适用于全部人物、场景和镜头，不允许局部覆盖。移除对象提示词中冲突的旧画风，但保留人物身份、服装、场景结构及剧情事实；全局风格由生成服务统一加入，不必反复复制进对象提示词。它不改变小说文风、对白、时长或工具权限。
```

```prompt:style-generation
本作品所有人物、场景和镜头统一采用上述画风。以下内容或参考图中的不同画风不能覆盖作品画风；保持人物身份、服装、场景布局、动作与剧情事实，将它们转绘为本作品的视觉风格。
```

```prompt:style-references
【画风参考】图片 {{positions}} 用于参考线条、上色、光影与材质表现，不把其中的人物或场景替换到当前剧情。其余参考按人物身份或场景结构使用。
```

## 六宫格（推荐）

```prompt:view-character-sheet
只生成一张横向人物六宫格设定合成大图，在同一张画布上严格按两行三列排版。上排从左到右依次为同一角色的正面、侧面、背面全身视图，三个全身视图等比例、等高度、基线对齐，完整展示原设定的身体形态与辅助器具，适当留白且互不遮挡。下排三格依次为正面面部近景、侧面面部近景、已确认的面部辨识特征或服装配饰细节特写；没有已确认的特殊细节时，第三格采用自然四分之三侧面面部近景，不凭空增加疤痕、饰品或身体特征。六格必须是同一人、同一套服装、同一体型比例与美术风格，依据已有参考保持辨识特征。基础描述中的单个人物指同一角色身份；本次六宫格只覆盖排版要求，保留全部身份、外貌、服装与身体事实。不补造缺失肢体，不镜像调换左右特征；侧面与背面只展示该方向真实可见的部分，不为露出正脸而扭转身体。采用符合人物设定的自然姿态；上下排保持一致背景与光线，背景简洁，无标题、文字标签、水印或场景故事。六格保存在同一张图片中，不分别输出六张图片。
```

## 三视图

```prompt:view-turnaround
只生成一张横向人物三视图合成大图，在同一张画布上从左到右依次横排正面、侧面、背面三个完整形态，三个视图等比例、等高度、基线对齐，适当留白且互不遮挡。基础描述中的单个人物指同一角色身份；若含单一视图、无多格拼图等限制，本次三视图布局只覆盖排版要求，保留全部身份、外貌、服装与身体事实。三个视图必须是同一人、同一套服装、同一体型比例与美术风格，不换装、不换人；依据已有参考图保持辨识特征。完整展示原设定的身体形态与辅助器具，采用符合人物设定的自然姿态，不补造缺失肢体，不镜像调换左右特征；侧面与背面只展示该方向真实可见的部分，不为展示正脸特征而扭转身体。背景简洁，无标题、文字标签、水印或场景故事；三视图保存在同一张图片中，不分别输出三张图片。
```

## 正面

```prompt:view-front
同一人物的正面全身定妆照，完整展示原设定的身体形态与辅助器具，采用符合人物设定的自然姿态，不补造缺失肢体，单个人物、单一视图，清晰五官，保持既定服装、发型与美术风格，简洁背景，无文字、水印或多格拼图。
```

## 侧面

```prompt:view-side
根据参考图生成同一人物的侧面全身视图，完整展示原设定的身体形态与辅助器具，不补造缺失肢体，身体与面部朝向一致，只呈现可见的一侧，不镜像调换左右特征，保留脸部轮廓、发型、服装、体型比例与美术风格，单个人物、单一视图，简洁背景，无文字、水印或多格拼图。
```

## 背面

```prompt:view-back
根据参考图生成同一人物的背面全身视图，完整展示原设定的身体形态与辅助器具，不补造缺失肢体，不回头露出正脸，不强行展示背面不可见的面部特征，保留发型、服装、体型比例与美术风格，单个人物、单一视图，简洁背景，无文字、水印或多格拼图。
```

## 表情

```prompt:view-expression
根据参考图生成同一人物的面部表情近景，按描述呈现一种表情，保留五官比例、脸型、肤色、发型与美术风格，单个人物、单一画面，简洁背景，无文字、水印或表情拼图。
```

## 服装

```prompt:view-outfit
根据参考图和服装描述生成同一人物的服装全身定妆照，只改变明确指定的新服装；没有新服装要求时展示原装束，不自行换装。保持脸型、五官、肤色、发型、体型与美术风格，完整展示原设定的身体形态与辅助器具，不补造缺失肢体，单个人物、单一视图，简洁背景，无文字、水印或多格拼图。
```
