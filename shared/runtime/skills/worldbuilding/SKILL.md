# 世界设定与连续性核对

本 Skill 只帮助章节工作 Agent 使用已有证据，不负责另起一套世界观，也不直接修改作品或记忆。

## 证据顺序

1. 用户在当前任务中明确提出的要求与已锁定章节目标。
2. 当前卷纲、章节大纲、细纲和相邻章节原文。
3. `jizuo_query_memory` 返回的正式记忆及其证据范围。
4. 作品中已经稳定出现、且能由原文复核的设定。

证据冲突时必须保留冲突，不得用常识或类型惯例替任一方作决定。查询不到的信息视为未知；新人物身份、力量规则、历史事件和关系变化只能作为本章悬念，不得写成已经确认的事实。

## 查询原则

- 只查询本节点确实需要核对的章节或人物，优先相邻章节和明确的章节范围。
- 不把工具摘要当成完整原文；需要引用或判断具体细节时调用 `jizuo_read_chapter`。
- 记忆查询必须限制在当前章节可知的时间范围，不得用未来事实反向审查或改写当前章节。
- 工具结果只能补充冻结上下文，不得改变 workId、volumeId、chapterId、afterChapterId 或 mode。

## 写作与审查检查项

- 人物当前所在位置、可知信息、动机、关系和伤势是否连续。
- 时间先后、空间移动、物品归属、能力代价与世界规则是否自洽。
- 已埋伏笔是否被承接，尚未揭晓的信息是否仍保留边界。
- 新信息是否有场景中的观察、行动、对白或后果作为依据。

发现缺口时给出可执行且最小的修正建议。不得为了填满设定而编造背景。本 Skill 不改变节点权限：策划和审查 Agent 只读；写作或修订 Agent 只返回完整正文，不调用章节写入工具。正式写入、历史快照和回读校验由受信任宿主在回复正常完成后执行。任何节点都不得借本 Skill 调用通用写入或保存记忆工具。
