# 小说文风与 AI 痕迹核对

判断目标是真实阅读质感和作品内部一致性，不是迎合检测器，也不是按词表消毒。作品既有章节的稳定声音、用户明确要求和当前场景功能优先于通用偏好。

## 宏观检查顺序

1. 叙事视角、时态和观察范围是否稳定。
2. 场景是否由人物欲望、阻力、行动与后果推进，而非由作者说明推进。
3. 相邻场景的进入、展开和收束方式是否重复成固定模板。
4. 人物对白互换后是否仍然成立；情绪是否真正改变用词、句长和表达完整度。
5. 句段长短是否随场景变化，是否连续出现功能相同的短句、单行段或人为顿挫。
6. 心理、主题、线索和意象是否在叙述、对白、总结中被重复解释或反复回收。

## 重点识别的机械模式

- “动作。动作。结论。”持续覆盖整段或整章。
- 先概括、再完整展开、最后再总结同一信息。
- 每个物件和停顿都精确服务伏笔，场景缺少自然连接和未完成状态。
- 过密的排比、对称句、格言式判断、章末升华与可摘抄金句。
- 空泛抽象、名词堆砌、泛用意象和套语集中出现。
- 所有人物都冷静、完整、准确地传递设定，缺乏回避、自我修正和言不由衷。

单次使用短句、破折号、对照句或常见词不是问题。只有形成可复核的重复模式并损害场景、人物或节奏时，才应列为修改要求。宏观问题至少引用两处证据；局部问题必须引用准确原句。

修改时优先撤掉一层解释、一次主题回收或一组重复结构，保留事实、视角、人物意图和场景功能。不得通过错别字、随机口癖、无意义残句、生硬俚语或逻辑漏洞制造所谓“真人感”。

本 Skill 不授予或撤销节点写入权限。审查 Agent 只报告证据与修改方向；写作或修订 Agent 只返回完整正文，不调用章节写入工具。正式写入、历史快照和回读校验由受信任宿主在回复正常完成后执行，记忆保存由对应工作流节点处理。
