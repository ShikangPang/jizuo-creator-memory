# 连贯剧情视觉制作（即作适配）

参考 MiniMax H3 的创作流程组织角色、环境与镜头。本技能是即作自己的工具适配层，不提供 MiniMax Hub 画布，也不安装或调用 Hub 工具。

## 从已有作品开始

加载 creative-prompt 和 novel-video，读取当前作品最新项目。人物、场景和镜头分别加载 character-prompts、scene-prompts、story-prompts。沿用当前作品画风、设定版本和用户已确认的比例、时长；不因采用本技能就改成 3D，不重复询问已给出的选择。缺少会影响结果的目标或规格时只询问缺失项。

## 准备图片与剧情

- 人物：先整理稳定身份、外貌、服装和辨识特征，保留设定库中的版本及参考图。基础 description 与视图排版分开；由 character-prompts 决定六宫格或用户指定视图。
- 场景：保存可复用的无人环境，写清门窗、家具、道路等空间关系。人物动作放在镜头里。
- 剧情：按视频集整理镜头；每镜明确人物位置、表情姿态、道具状态、光线与构图，并检查与前后镜头的承接。静态图片提示词不混入时长、声音或运镜时间线。
- 视频：在静态画面基础上描述能够在已定时长内完成的动作和运镜。人物身份与场景位置保持连续，对白保持原文。超出单镜承载能力时提出拆镜建议，获得相应修改意图后再改变制作稿。

已有对象的提示词按 creative-prompt 的版本与锁定规则保存，设定使用 jizuo_replace_design_prompt；剧情保存用 novel-video 中现有镜头工具。无法完成写入时保留文本并说明原因，不声称已保存。

## 生成与交付

只有用户明确要求生成图片或视频时，才通过 novel-video 中的 jizuo_generate_video_media 提交。先检查已配置模型、输入能力及旧任务，复用真实素材 ID；不绕过即作调用外部脚本，不编造 hub_generate_image、hub_generate_video 或画布节点。

创建提示词不等于付费生成。参考图未实际读取时不能声称已核对外观。新结果沿用即作素材保存和命名机制，人物／场景归入作品设定库，镜头素材关联所属集与镜头；不直接移动已登记素材。

用户明确指定 H3 提示词时加载 h3-prompt-writing。该技能仅输出 H3 格式文本，不能据此宣称已接通 H3 API；未配置支持该模型的连接时说明这一点，不静默切换到其他模型。
